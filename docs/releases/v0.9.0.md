## Compatibility and scope

This compatible additive MINOR contains
[CORE-CAP-001](../core/capabilities-001.md): closed capability descriptors,
provider registration invariants and authenticated effective catalogue/detail
discovery. WMS owns three existing list capabilities. The current administrator
policy maps their functional permissions without changing existing routes or
introducing permission assignment. Disabled, absent and unauthorized capabilities
are hidden; detail uses `capability_not_found` in the existing global envelope.
Schema references reuse the selected bundled OpenAPI. Execution is excluded.

standard error envelope. Those behaviors are preserved; they are not new v0.9.0
features. The v0.8.0 tag and historical release notes remain unchanged. The original preparation did not itself authorize publication or consumer pin

`v0.9.0` tag recorded above; consumer adoption remains separate. Capability
behavioral versions remain `1.0.0`, independent of the ERBAS contract release.
