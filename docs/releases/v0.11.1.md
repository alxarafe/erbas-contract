# ERBAS Contract v0.11.1 preparation

**v0.11.1 is prepared but not published and has no tag**, a compatible PATCH over
published immutable [v0.11.0](v0.11.0.md). No consumer change, backend/client
adoption, live conformance or publication is claimed. Do not publish or tag this
revision without the separately authorized release procedure in
[versioning](../common/versioning.md).

## Compatibility and scope

This PATCH increases only the full conformance runner timeout from 120 to 180
seconds. The scoped 30-second and ItemFamily 90-second watchdogs are unchanged.
The synthetic full-suite outer test budget is raised from 130 to 190 seconds so it
still exceeds the runner watchdog and leaves time for fixture cleanup.

No HTTP behavior changes. Routes, methods, request and response schemas, bodies,
status codes, headers, permission requirements, module and capability identities,
Bruno scenarios, fixtures, assertions, provider neutrality and shared errors are
unchanged. The collection remains **590 requests / 2587 named checks**. The
OpenAPI version advances to **0.11.1** only to record this compatible runner PATCH.

Published v0.11.0 CORE, authentication, user, module, collection, capability, WMS
and AI behavior remain unchanged. No backend or client change, tag, GitHub Release
or deployment is part of this preparation.

## Verification

Repository validation ran in Docker and examined synthetic fixtures only.

the full suite completed all 199 tests, including the 590-request /
2587-named-check collection, with no failures. No external backend was examined,
and no backend conformance or live-provider behavior is claimed.
